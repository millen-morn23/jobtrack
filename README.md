# JobTrack

JobTrack is a web application that helps job seekers organize their job applications, track their progress through the hiring process, and manage related company and contact information.

## Purpose

JobTrack gives job seekers one place to manage their job search and keep track of where they have applied, what stage each application is in, and important information about companies and contacts.

## Core Features

* Job application tracking
* Application dashboard
* Company and contact management
* User authentication
* Application status tracking
